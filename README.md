# Roblox Top Games — Design Vault (Obsidian)

An Obsidian vault that tears down the games at the top of Roblox in **November 2026** — Steal An Egg, Throw Food For Animals, RIVALS, Steal a Brainrot, Brookhaven RP, Blox Fruits, Murder Mystery 2, Adopt Me!, 99 Nights in the Forest, Fish It!, Pet Simulator 99 and Forsaken, plus the rising games behind them.

It covers each game's **HUD and GUI, gameplay mechanics, intuitiveness, art style, map, models, pets, animations, fonts, shop and game passes**, why each one performs, and step-by-step **playbooks with Luau code** for building the same systems.

A **Models** section covers how the top games' models are built (creatures, pets, eggs, weapons, buildings, props) and step-by-step **model creation** — Blender/Blockbench/Studio pipeline, budgets, voxel creatures, cube pets and variants, rigging — with a starter kit of importable example models.

## Open it

1. Install [Obsidian](https://obsidian.md).
2. **Open folder as vault** → choose `Roblox Design Vault/`.
3. Start at **`00 Home`** (also bookmarked). The CSS snippet `roblox-vault` is already enabled for image galleries.

## Data & images

- **Numbers** (players, visits, favorites, like ratio, server size, game pass names/prices/descriptions, chart ranks) come from Roblox's public APIs, captured **2026-11-12**. They are a snapshot.
- **Official images** in `99 Assets/Games/` are the developers' own store icons, thumbnails and pass icons, kept for study and reference. © their respective creators.
- **Mockups** in `99 Assets/Mockups/` are original illustrations. The HUD "layout studies" are **reconstructions**, labelled as such on every image, not in-game screenshots.
- **Example 3D models** (renders in `Mockups/model-*.jpg`, files in `Models/Starter Kit/`) are original, procedurally built teaching assets.
- Every claim in the notes carries a tag: ✅ official data · 📰 third-party guide · 🔎 seen in official store images · 🧠 analysis.
