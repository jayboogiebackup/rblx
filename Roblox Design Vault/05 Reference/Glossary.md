# Glossary

| Term | Meaning |
|---|---|
| **Admin abuse** | A scheduled live event where developers use admin powers in public servers (spawning rares, x2 boosts, chaos). Drives appointment play and clips. |
| **Archetype (HUD)** | The four HUD layouts in [[HUD Design]]: A simulator, B FPS, C social, D survival. |
| **BillboardGui** | UI attached to a 3D object that always faces the camera (pet names, prices, timers). |
| **Brainrot** | Internet slang for absurd meme content; also the collectible creatures in [[Steal a Brainrot]]. |
| **CCU** | Concurrent users — players online at the same moment ("playing" in the API). |
| **Core UI / top bar** | Roblox's own buttons (menu, chat…) at the top-left; your UI must avoid them. |
| **D1 / D7 retention** | Share of new players who return 1 / 7 days later. |
| **Developer Product** | A repeatable Robux purchase (boosts, currency, skips). Granted via `ProcessReceipt`. |
| **Game Pass** | A one-time, permanent Robux purchase (x2 money, VIP…). Checked with `UserOwnsGamePassAsync`. |
| **Index** | A collection book showing found/unfound collectibles, often with completion rewards. |
| **Juice** | Feedback polish: tweens, popups, particles, sound, camera shake. |
| **Like ratio** | Up-votes / (up + down) on the store page. Top-12 range: 82.8–94.7%. |
| **Mutation** | A random variant (Golden, Rainbow…) that multiplies a collectible's value. |
| **ProximityPrompt** | Roblox's built-in "press/hold E" interaction with verb + object text. |
| **Rebirth / prestige** | Reset progress for permanent multipliers. |
| **ScreenInsets** | `ScreenGui` property controlling safe areas (`CoreUISafeInsets` avoids notches + Roblox UI). |
| **Secret / OG / Godly** | Top rarity tiers above Mythic in various games. |
| **Steal-a-X / steal-tycoon** | The genre started by Steal a Brainrot: bases earn money; players steal from each other. |
| **StreamingEnabled** | Workspace setting that loads only nearby parts on clients. |
| **UIGradient / UIStroke / UICorner / UIScale** | Roblox UI modifiers for gradients, outlines, rounded corners and scaling. |
| **Visits** | Total game joins since creation. |
