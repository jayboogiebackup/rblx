# Sources

> [!info] How to read the confidence tags
> - ✅ **Official Roblox data** — pulled directly from Roblox's public endpoints on **2026-11-12** (~18:10 UTC): `games.roblox.com/v1/games` (details, visits, favorites, server size, description), `games.roblox.com/v1/games/votes`, `thumbnails.roblox.com` (icons, store thumbnails, pass icons), `apis.roblox.com/game-passes/v1/universes/{id}/game-passes` (names, prices, descriptions), `apis.roblox.com/explore-api/v1/get-sorts` (Top Playing Now, Top Trending, Up-and-Coming).
> - 📰 **Third-party guides** — listed below; several disagree with each other on numbers (mutation multipliers, zone counts, pet counts). Treat specific numbers as approximate.
> - 🔎 **Official store images** — observations from the developers' own thumbnails (see [[Visual Index]]).
> - 🧠 **Analysis** — this vault's interpretation; HUD studies are reconstructions, not captures.
