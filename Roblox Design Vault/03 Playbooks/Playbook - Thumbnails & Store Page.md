# 🛠️ Playbook — Thumbnails & Store Page

> [!summary] Goal
> An icon, a 6-image thumbnail series and a description that sell **one verb** to someone scrolling on a phone — following the patterns in [[Thumbnails & Icons]].

![[anno-steal-an-egg-chase.jpg]]

## Step 1 — Write the one-line pitch

`[verb] [object] to [reward] — but [threat/twist]` → "Steal eggs from monsters to hatch rare pets — but other players can steal them back."

## Step 2 — Shot list (6 thumbnails, one template)

Pick a **fixed composition** (e.g. 'threat left, player right with the prize, text top'). Swap one variable per image:

| # | Variable swapped | Example |
|---|---|---|
| 1 | Biome/threat 1 | snake in meadow |
| 2 | Biome/threat 2 | T-Rex in desert |
| 3 | Biome/threat 3 | Yeti on ice |
| 4 | Rarest item | cosmic egg |
| 5 | Social/PvP moment | getting robbed |
| 6 | Event variant | Halloween |

![[anno-thumbnail-series.jpg]]

## Step 3 — Stage & render in Studio

1. Build a small diorama per shot (no UI, no clutter). Scale the **prize up** (eggs bigger than the avatar are fine — 🔎 Steal An Egg does it).
2. Pose characters with exaggerated, readable poses (lifting, fleeing, straining, crying).
3. Lighting: bright key light, saturated sky, strong rim/outline; for horror, one warm light in darkness.
4. Use the **default avatar** or a recognisable one (🔎 most top thumbnails use the classic 'bacon hair').
5. Capture at **1920×1080** (thumbnails) and **512×512** (icon).

## Step 4 — Paint-over

- Add a **thick white sticker outline** around characters and the prize.
- Add **motion lines**, a red **'!!'**, a **'YOU!'** arrow.
- Add **one text block max**: item name with a rarity gradient + an outlined green number (income/s or odds).
- Check at **10% size** — if you can't read the story, simplify.

## Step 5 — Icon

One subject, mid-action, filling the frame, outlined, simple background. No small text. Make it readable at 64 px.

## Step 6 — Title & description

- Title: verb-first (*Steal An Egg*). Add update tags when live (`[UPD]`, `[🎃]`, `[🌙UPD]`).
- Description template:

```text
🥚 Welcome to <Game>!

How to Play:
<emoji> <verb line 1>
<emoji> <verb line 2>
<emoji> <verb line 3>
<emoji> <verb line 4>
<emoji> <verb line 5>
<emoji> <verb line 6>

🎮 Supports Desktop, Console, Mobile, and Tablet players
👍 Like & ⭐ Favorite + join the group for a free reward!
```

## Step 7 — Test & iterate

- Use the Creator Hub's thumbnail testing / personalization tools where available; compare click-through and play-through, not likes.
- Swap the hero thumbnail each update/event; keep the template.
